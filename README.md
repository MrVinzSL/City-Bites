## 🚀 Project Overview

**UrbanFood** is a cutting-edge e-commerce platform designed to connect **urban farmers & local producers** directly with **consumers** who value **fresh**, **local**, and **handmade** goods 🌽🥛🍞🎨.

Buy & Sell:
- 🥬 Fruits & Vegetables
- 🧀 Dairy Products
- 🍞 Baked Items
- 🧵 Handmade Crafts

---

## 🧠 Developer Focus – Backend & Data

🎯 **Goal**: Build a scalable system managing the full e-commerce cycle:

> 👨‍🌾 Suppliers → 🛒 Products → 👥 Users → 🧾 Orders → 💳 Payments → 🚚 Deliveries

Using a **hybrid database approach**:

- 🟠 **Oracle** – For structured, transactional data with PL/SQL logic
- 🟢 **MongoDB** – For flexible, user-generated content (like reviews)

---

## 🛠️ Modules & Features

### 🧑‍🌾 Supplier
- ✅ CRUD procedures
- 🔐 Login function
- 🕵️ Trigger logs deletions → `Supplier_Audit`

### 👥 Users
- ✅ CRUD operations
- 🔐 Secure login
- 🕵️ Trigger logs deletions → `User_Audit`

### 📦 Product
- 🧰 Full CRUD system for products

### 💳 Payments
- 🔎 Search by Payment ID or User ID
- 🧾 Trigger logs deletions → `Payment_Audit`

### 🛒 Orders
- 🔄 Complete CRUD
- 📊 Extra procedure returns 3 key values
- 📉 Trigger logs deletions + updates stock

### 🚚 Deliveries
- 📬 Delivery handling with audit trail
